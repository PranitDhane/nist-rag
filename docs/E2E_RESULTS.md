## Limitations

- The support score (group D) uses the same reranker model as retrieval, so it is not an independent judge; a sentence can score high on topic overlap with a subtle factual error. The gold facts (B) and the citation checks (C) complement it.
- Temperature 0.2 means wording can differ between two runs of the same question; each case ran once, so single results carry variance.
- Fact matching is lexical (case-insensitive, hyphen-insensitive, word-start prefix): a correct answer in other words can miss a fact, and a fact word in a wrong context can count.
- Sixteen requests is a small sample: the percentages are descriptive, not statistically tight.
- The English check is a heuristic (script and common English words).
